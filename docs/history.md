# 開発履歴

ファイル名の版番号は、`v120` がv12.0、`v112` がv11.2のように対応します。新しい版がすべての指標で最良とは限りません。

| 版 | 調べたこと | 結果の要点 |
|---|---|---|
| v0.1〜v0.7 | 局所予測、記憶、生成制御、特徴表現 | 初期の探索 |
| v0.8〜v0.88 | ノードの新生・削除・統合、UTF-8バイト化 | 256バイトだけを入力とする成長グラフに移行 |
| v0.9〜v1.2 | 作業記憶、長短期記憶、継続学習、文章モード制御 | 100万→500万ノードの器へ拡張 |
| v1.3〜v1.4 | 3分野混合、関連概念、9,000万文字の継続学習 | 約314万ノード。BPCはほぼ横ばい |
| v2.0〜v2.0b | 着脱できる外部バイト記憶、ゲートの調整 | 装着でBPC 5.92→3.40、取り外しで元に戻る |
| v2.1 | 文章検索記憶 | BPCは下がるが、生成では固有名詞が崩れる |
| v2.2 | pointer生成、600万ノード枠 | 本体BPCが3分野とも悪化 |
| v3.0〜v3.1 | 根拠を使う生成探索、投機的な候補処理 | 生成の品質と速度の探索 |
| v4.0〜v5.2 | 可変長のバイト単位（モーター単位）、連続表現 | バイト基盤との統合、因果的評価の整備 |
| v6.0〜v6.4 | 役割表現（HRR）、独立スロット、構文ゲート | 語順・役割と話題制御の切り分け |
| v7.0 | 48,000モーター、17役割に拡大 | 連続表現による平均BPCの差は小さい |
| v8.0〜v8.1 | SFT記憶、読み出し適応、終了予測 | 本文予測とEOT予測が改善 |
| v9.0 | 応答意図への経路選択 | 自己採点の低損失と回答の正確さは一致しない |
| v10.0〜v10.1 | 対話専用DAG | 対話本文BPCは改善、QAの語句一致は低い |
| v11.0〜v11.1 | 構造対応によるDAG統合 | GPU割当は減ったが一般文章の保持が悪化 |
| v11.2 | 記事冒頭文を優先する検索 | 小規模QAの語句一致が1/15→10/15 |
| v12.0 | 学習型の記憶ゲート | 無関係な根拠は抑えるが、回答の欠落が増加 |
| v12.1〜v12.3 | 棄権、冒頭文の品質、認識と発話温度の分離 | 温度を上げても認識結果が変わらない |
| v12.4 | 語彙・意味・語用の判定と合議 | 小規模な既知問題で動作 |
| v12.5 | 成長型仲裁層（23ノード） | 31問で単一ゲート・合議と同水準 |
| v13.0 | ツールの登録と呼び出し（計算・時計・本文検索） | 新規10問 2→4。追加部品のCUDA割当0 bytes |
| v13.1 | ツール選択と発話を別部品にした2×2比較 | 新規10問 2 / 4 / 2 / 5（なし / A / B / A＋B） |
| v13.2 | 外部行動と記憶の判断の二軸化 | 新規10問 3/10。文章題の数値は改善、単位と時計の言い換えは失敗 |
| v14.0 | 教示・訂正・睡眠による世代の更新と復元 | 教えた事実に言い換えでも回答。嘘の教示は固定検査で自動棄却 |
| v15.0 | メタ認知（発話前の監査・再検索・自信度） | 新規10問 1→3。増分は未来の人数を問う罠の棄権 |
| v15.1 | メタ認知の修正と校正 | 固定算術4/4に回復。新規10問 5→4 |
| v15.2 | 自信度の校正と比較質問の保護 | 開発用50問で自信度の順序が正答率と一致。新規10問 6→5 |
